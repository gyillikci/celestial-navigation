Introduction
============
This archive contains the revised query set for the paper "Large Scale Visual
Geo-Localization of Images in Mountainous Terrain" by Georges Baatz, Olivier
Saurer, Kevin Köser, and Marc Pollefeys.

Files
=====
image.png
The photograph.

image-mask.png
Segmentaion of image.png as a black-and-white image.

image.png.txt
Metadata for image.png. One item per line:
- Focal length (pixels)
- Ground truth latitude (degrees)
- Ground truth longitude (degrees)
- Unused (-1)
- Image width (pixels)
- Image height (pixels)
- Image name
